# pixbox

pixbox 是一个面向原始视频数据的可视化工具，主要用于查看和调试像素格式、色彩空间以及颜色变换对图像内容的影响。它提供了一个基于 PySide6 的桌面播放器界面，便于打开原始二进制视频帧、切换色彩参数并观察结果。

## 适用场景

这个项目的目标不是“通用视频播放器”，而是为视频和图像工程师、算法开发者提供一个便于验证颜色与像素格式的工具，可以把它理解为一个轻量的“像素格式与色彩空间调试器”。

## 主要功能

- 支持打开原始二进制视频帧并进行播放预览
- 支持切换常见的颜色主、颜色传输函数、颜色范围和像素格式
- 内置对 RGB/BGR、YUV420/422/444 等格式的处理能力
- 提供帧导航、缩放、保存当前帧等基本操作
- 可作为 Python 包或桌面应用来使用

## 环境要求

- Python 3.12 或更高
- 推荐使用 uv 管理依赖
- 运行时依赖包括 numpy 和 PySide6

## 安装与运行

### 作为 Python 包使用

推荐使用 uv：

```bash
uv sync
uv run pixbox
```

如果使用传统 pip，也可以这样安装并启动：

```bash
python -m pip install -e .
python -m pixbox
```

### 使用已打包的二进制产物

直接运行对应的项目发布出来的可执行文件即可。通常它会提供与上面相同的文件打开、设置和播放体验。

## 基本使用流程

1. 选择“Open”打开一个原始文件。
2. 在“Settings”中设置像素格式、颜色空间、颜色范围和帧尺寸等参数。
3. 使用播放控制查看不同帧内容。
4. 根据需要保存当前帧或调整缩放级别。

## 作为 Python 包进行集成

如果你希望把 pixbox 集成到自己的脚本或工具链中，可以先安装项目并通过 Python 入口启动界面。对于更深入的二次开发和构建流程，请参阅 [CONTRIBUTING.md](CONTRIBUTING.md)。
